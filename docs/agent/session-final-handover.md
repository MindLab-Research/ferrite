## 1. 范式转移：损坏是模型行为（最核心发现）

**证据链**：
- 所有配置（base/spec 最小/R2/K1+K2/lin2-only）在计数 line 62 相同损坏（'12'）
- **纯 EAGER+e4m3 也在 line 62 损坏**（61/77）——不走 spec 也损坏！
- 出师表：EAGER+e4m3 也有拉丁（'acs' @ ~100 字）
